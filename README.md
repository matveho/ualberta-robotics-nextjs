## <center>Website for University of Alberta Robotics Association</center>

### Introduction
UARA is a group of students who are passionate about robotics and bringing cool projects into reality.

### Website Dev Start
To try out this version of the website or to contribute to it, clone the repository into your desired local directory and run `npm run dev` or `yarn dev`.

### Structure
Pages of the website are located in the directory `./src/`. Further, the directory `./src/app` is the index page of the website and `./src/components` is the directory with different components of the website (i.e. navbar, footer, hero, etc.).
